# Win11 Dock Animations

Набор Windhawk-модов для Windows 11 с двумя связанными эффектами:

1. `win11-dock-taskbar.wh.cpp` — увеличение иконок панели задач при наведении курсора.
2. `win11-window-icon-animation.wh.cpp` — анимация окна из/в иконку Taskbar при открытии и закрытии.

Основная идея:
- окно не использует Genie-деформацию;
- исходная точка берётся из реальной кнопки приложения на Taskbar;
- размер окна плавно интерполируется от размера иконки к реальному размеру;
- при закрытии выполняется обратная анимация;
- Taskbar использует XAML-визуальное дерево Windows 11;
- поддерживается несколько мониторов.

## Установка

Откройте Windhawk -> Create a new mod и вставьте соответствующий `.wh.cpp`.
Для полного эффекта установите оба файла.

## Примечания

`win11-dock-taskbar.wh.cpp` использует архитектуру Taskbar Dock Animation Plus из официальной коллекции Windhawk; сохранена атрибуция исходного автора.

Анимация окна является отдельной реализацией и намеренно использует более простой scale/position-подход вместо Genie.
